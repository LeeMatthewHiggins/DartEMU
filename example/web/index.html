Inspect the machine

Ask Linux for its architecture and CPU details.

uname -m
cat /proc/cpuinfo

Expected: riscv32 and the guest CPU details.

Record temperatures

Use > to save four temperatures in Celsius to a file.

mkdir -p /tmp/tutorial
printf '%s\n' \
  'roof 18' 'garden 24' \
  'attic 31' 'cellar 16' \
  > /tmp/tutorial/weather.txt
cat /tmp/tutorial/weather.txt

Expected: Four rows saved in /tmp/tutorial/weather.txt.

Find the warmest places

Sort these two-digit readings as text, then use head to keep the warmest two.

printf '%s\n' \
  'roof 18' 'garden 24' \
  'attic 31' 'cellar 16' |
  sort -r -k2 | head -n 2

Expected: attic 31 and garden 24.

Draw a temperature chart

Use a shell loop to draw one # for each degree Celsius.

printf '%s\n' \
  'roof 18' 'garden 24' \
  'attic 31' 'cellar 16' |
  while read place temp; do
    printf '%-7s ' "$place"
    i=0
    while [ "$i" -lt "$temp" ]; do
      printf '#'; i=$((i + 1))
    done
    echo " $temp C"
  done

Expected: Four bars, with the longest at attic 31 C.

Render a fractal

Compute the Mandelbrot set with integer arithmetic, and increase limit for more detail.

limit=16
y=-8
while [ "$y" -le 8 ]; do
  row=; x=-30
  while [ "$x" -le 10 ]; do
    a=0; b=0; n=0
    while [ "$((a*a+b*b))" -le 40000 ] &&
          [ "$n" -lt "$limit" ]; do
      t=$(((a*a-b*b)/100+x*7))
      b=$((2*a*b/100+y*14))
      a=$t; n=$((n+1))
    done
    case $n in
      "$limit") p=@;;
      [0-2]) p=' ';;
      [3-5]) p=.;;
      [6-9]) p='*';;
      *) p=+;;
    esac
    row="$row$p"; x=$((x+1))
  done
  printf '%s\n' "$row"
  y=$((y+1))
done

Expected: a computed 41 by 17 fractal, with @ marking points that reach the limit.
